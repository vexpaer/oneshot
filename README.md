# OneShot

A small gallery for browser experiences generated in a single pass.

> **All six webpages in this repository were created by Fable 5.1 using a OneShot workflow.**

## Projects

- `school-sandbox` — 山城校园 3D
- `nature-explorer` — Nature Explorer · 自然探索之境
- `cardistry-lab` — Cardistry Lab · 花切实验室
- `desk-wars` — Desk Wars
- `zhen-huan-incremental` — 紫禁春秋 · 甄嬛传 3D 增量游戏
- `zhen-huan-idle` — 甄嬛传 · 六宫 3D 增量游戏

Each original project is preserved under `projects/`. The root GitHub Actions workflow builds every project and publishes one gallery where `index.html` links to all six pages.
