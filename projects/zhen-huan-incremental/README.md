# 紫禁春秋 · 甄嬛传 3D 增量游戏

> 皇上的心只有一颗，六宫都在分它。

一款以《甄嬛传》为世界观的纯前端 3D 增量游戏（React + Three.js / React Three Fiber + Zustand + Tailwind）。
构建产物为单个 `dist/index.html`，可直接部署到 GitHub Pages。

## 核心循环

| 层次 | 机制 |
| --- | --- |
| **恩宠** | 请安（点击 / 空格 / 点击 3D 宫殿）与宫务（宫女、太监、小厨房、敬事房……）持续产出，用于打点与晋封。 |
| **位分** | 秀女 → 答应 → 常在 → 贵人 → 嫔 → 妃 → 贵妃 → 皇贵妃 → 皇后 → 太后。每级 ×1.5 恩宠，3D 宫殿随之扩建、屋瓦换色、庭院添梅栽池、季节更替。 |
| **圣心** | 皇上的心是被所有嫔妃共享的稀缺资源。你的份额 = 你的势力 / (你 + 所有在世对手)，直接决定恩宠倍率，也是晋封的硬门槛。 |
| **心机 × 嫌疑** | 常在起积累心机，用挑拨 / 构陷 / 借刀杀人削弱对手；每位对手都有专属「杀招」（一丈红、欢宜香、苦杏仁、滴血验亲、死生不复相见）。每一步都累积嫌疑，满 100 则「事发」：降位、恩宠折半。 |
| **人脉** | 沈眉庄、温实初、崔槿汐、端妃、苏培盛、敬妃、果郡王、叶澜依——各自改变局势，部分解锁自动化或关键剧情。果郡王给予最大加成，也持续制造嫌疑。 |
| **事件** | 杏花微雨、惊鸿舞、木薯粉、年羹尧、滴血验亲、桐花台……每个事件都是真实的抉择，影响资源、对手、盟友与藏品。 |
| **甘露寺（转生）** | 晋至「妃」后可出宫修行。归零换取「道行」，永久提升恩宠并修习秘法（钮祜禄氏起步、熹、菩提心、自动请安、自动打点……）。回宫后才能触及贵妃以上的位分与皇后之争。 |
| **藏品** | 18 件跨轮回永久保留的物件，各带被动加成。 |

## 本地开发

```bash
npm install
npm run dev
npm run build   # 产出 dist/index.html（单文件）
```

## 部署

仓库已包含 `.github/workflows/deploy.yml`，推送到 `main` 即自动发布到 GitHub Pages（Settings → Pages → Source 选择 *GitHub Actions*）。
