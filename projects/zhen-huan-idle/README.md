# 甄嬛传 · 六宫 — 3D 增量游戏

从秀女到太后的一场漫长晋升。请安积攒恩宠，置办宫人自动生产，以银两结交盟友，以心计扳倒对手，每夜等待皇上翻牌子；嫔位之后穿上纯元故衣、自请出宫，在甘露寺换得佛心，再以钮祜禄氏的身份回宫……直到太后之位，开启新朝。

## 核心循环

| 层次 | 机制 |
| --- | --- |
| 秒级 | 请安（点击宫殿 / 按钮 / 空格）、殷勤连击 → 圣心大悦 |
| 分钟级 | 置办宫人与强化、结交盟友、置办珍玩、翻牌子之夜（48 秒一日，龙辇真实驶向被翻牌的宫殿） |
| 十分钟级 | 位分晋封（宫殿在 3D 中长大）、积攒心计一击扳倒对手（宫殿被封条封死）、宫中事件抉择 |
| 小时级 | 甘露寺出宫修行（转生，得佛心修习永久法门）、太后 → 新朝（凤印传承） |

关键设计：
- **恩宠 / 银两 / 心计 / 佛心** 四种资源各司其职，互不可换。
- **对手不是数字**：她们分走翻牌子的机会、会陷害你，而且势力会缓慢恢复——必须攒够心计一击致命。晋贵人须扳倒夏冬春，晋妃须扳倒华妃，晋太后须扳倒皇后。
- **盟友出宫不散**：转生保留盟友与已倒台的对手，第二次入宫从容得多。
- 所有事件奖励按当前产出比例计算，任何阶段都有意义。

## 工程

- React 19 + Vite 7 + Tailwind 4 + Three.js（@react-three/fiber / drei）+ zustand
- 纯前端，`npm run build` 产出**单个** `dist/index.html`，可直接丢到 GitHub Pages / 任意静态托管，不依赖 base path。
- 本地存档：每 10 秒 + 页面隐藏 / 关闭时写入 `localStorage`；重新打开结算离线收益（上限 8 小时，效率 50%）。
- 无 WebGL 或 3D 初始化失败时自动降级为平面背景，游戏全部功能不受影响。
- 低画质模式关闭阴影、抗锯齿并降低粒子数与 DPR。

## 部署到 GitHub Pages

```bash
npm install
npm run build
# 将 dist/index.html 提交到 gh-pages 分支根目录，或在仓库 Settings → Pages 选择 /docs 并把 dist/index.html 复制为 docs/index.html
```
